# RQ1: forecasting accuracy (non-graph models)

This folder holds the non-graph forecasting models for RQ1 and the shared dataset they
are evaluated on, so the baselines and the neural network are directly comparable.

## Contents
- 'baseline_nongraph.ipynb' - Kaushik: persistence, seasonal, and linear regression.
- 'alice_nn.ipynb' - Alice: small neural network (add here).
- 'data/forecast_dataset/' - the shared dataset: 'features.npz', 'params.npz', 'windows.csv'.

## Running
Open either notebook and Run All. Both read `data/forecast_dataset`, so they train and
test on the same sensors and the same train/val/test split. Scores are MAE and RMSE in
vehicles/hour at the 15, 30, 45 and 60 minute horizons, on observed targets only.

## The dataset
6 connected central districts, about 1,054 sensors, 2024, 15-minute steps. Generated by
the shared pipeline on `main`:

    python -m preprocess.run --selection districts --n-districts 6

Everyone in RQ1 must use this exact dataset, so the model numbers line up.
